## 📌 About

This repository contains my solutions to the exercise lists of **AE-245 (Finite Element Method)**, taken at the **Instituto Tecnológico de Aeronáutica (ITA)**, in São José dos Campos, Brazil.

Each exercise is solved in its own **Jupyter Notebook**, combining the derivation, the code and the results. The lists start from approximate solutions with weighted residual methods and move on to the Finite Element Method itself, including 2D trusses and Euler-Bernoulli beams.

> 📚 Notebook names and some comments are in Portuguese, since the course was taught in Portuguese. "Lista" means "exercise list", "Questão" means "question" and "Prova" means "exam".

## 🚀 How to run

**1. Clone the repository**

```bash
git clone https://github.com/RenanMP12/AE-245.git
cd AE-245
```

**2. Install the dependencies**

```bash
pip install jupyter numpy scipy sympy matplotlib
```

**3. Open the notebooks**

```bash
jupyter notebook
```

Then pick any `.ipynb` file from the list. GitHub also renders the notebooks directly in the browser, so you can read them without installing anything.

## 🛠️ Technologies

- **Python 3.10+**
- **Jupyter Notebook**: derivations, code and results in one place
- **SymPy**: symbolic calculus (weighted residual methods, literal solutions)
- **NumPy** and **SciPy**: linear algebra and numerical computation
- **Matplotlib**: plots of the results
